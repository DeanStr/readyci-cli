# Contributing

Ready CI publishes the CLI, protocol contracts and shared libraries under
Apache-2.0 so customers can inspect, build and modify the client they run.
The public repository is maintained by Ready CI. We currently accept bug reports
and feature requests, but not external code contributions or pull requests.
Maintainer changes are published from the private development repository.

This contribution policy does not limit your rights to fork, modify or
redistribute the code under [LICENSE](LICENSE). Please respect
[TRADEMARKS.md](TRADEMARKS.md) when distributing a modified version.

For a useful bug report, include the CLI version, operating system, reproduction
steps and expected versus actual behavior. Never include credentials, customer
source, private host details or unredacted logs. No support or response-time
guarantee is implied by publication.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not the public
issue tracker. Participation is governed by
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
