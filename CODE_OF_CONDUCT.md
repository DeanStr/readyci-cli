# Code of Conduct

We are committed to a respectful, harassment-free project for everyone.
Contributors must communicate constructively, respect differing viewpoints,
avoid personal attacks and discriminatory language, and protect private or
sensitive information shared during project work.

Unacceptable behavior may be reported privately to the project maintainers
using the private contact in [SECURITY.md](SECURITY.md). Maintainers may edit or
remove contributions, comments, or participation that violate these
expectations. Reports will be reviewed as confidentially and fairly as
practical, with actions proportionate to the circumstances.

This policy applies in project spaces and when representing the project in
public spaces.
